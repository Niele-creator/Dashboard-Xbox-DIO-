# 📊 Xbox Game Pass Dashboard

Dashboard Excel para análise de assinaturas.  
**Versão:** 1.0 | **Atualizado:** Ago/2023  

---

## 🚀 Funcionalidades
- **KPIs:** Faturamento total, planos anuais, EA Play.  
- **Gráficos:** Pizza (tipos de plano) e barras (renovação).  
- **Filtros:** Por plano, tipo e renovação.  
- **Cores Personalizadas:** Paleta Xbox (#9BC848, #22C55E, #E8E6E9).

---

## 🛠️ Como Usar
1. **Dados:** Atualize a planilha `Bases` (formato: Tabela Excel).  
2. **Dashboard:**  
   - Interaja com *Slicers* e gráficos.  
   - Atualize via `Dados > Atualizar Tudo`.  
3. **Cores:** Edite códigos HEX em `Assets`.

---
